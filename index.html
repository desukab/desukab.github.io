02 / THE PRODUCT

The first editorial pass should not take all day.

A long recording contains stories, dead air, repetition, context and moments worth publishing. SelekyT is being built to find and shape those moments before the human editor takes over.

EDITORIAL INTELLIGENCE

From raw footage to decisions.

SelekyT analyzes a long-form source, builds a structured representation of what was said, groups story units, applies editorial reasoning and produces concrete edit decisions.

INPUT long-form video
↓ transcription
↓ story-unit detection
↓ editorial reasoning / ranking
↓ context & truth checks
↓ filler / dead-air analysis
↓ reframing + captions
OUTPUT editable editorial package
HUMAN CONTROL

AI proposes.
You decide.

The goal is not to replace editors. It is to remove repetitive first-pass work and preserve professional editorial control.

FORMAT

One source.
Many outputs.

Selections, transcripts, captions, 16:9 and 9:16 renders, and editable timeline representations can all come from the same editorial analysis.

04 / ENGINEERING

Built as an editorial system, not a demo wrapper.

The project combines a Python editorial layer, a Rust mechanical core, deterministic validation and a web/desktop surface. The architecture is designed so AI decisions can become measurable, testable parts of a real editing workflow.

Python editorial layer

Transcription, story grouping, editorial logic, context safeguards and orchestration.

Rust core

Mechanical media operations and performance-sensitive processing.

Editable timelines

FCPXML and CMX 3600 EDL generation with structural validation.

Desktop direction

A local-first Windows application is being productized around the same engine.
